## How to use this backlog

Work is ordered by dependency, not by the order in which ideas appear in the guide. A later item must not be treated as complete until its dependencies and acceptance checks are complete. “Blocked” means the work genuinely needs owner confirmation, a deployed site, historical data, or an external account; it does not mean local preparation was skipped.

## Recommended execution sequence after this local implementation

1. Review the generated crawl and fix any genuine local failures.
2. Send only `OWNER-QUESTIONNAIRE-1.md` to the owners; do not send the whole implementation guide.
3. Obtain Search Console and Bing exports, then populate the search baseline and historical URL list.
4. Resolve claim evidence before expanding authoritative content.
5. Deploy the tested local changes.
6. Verify redirects, sitemap and structured data on production.
7. Submit priority URLs through Search Console/Bing and optionally IndexNow.
